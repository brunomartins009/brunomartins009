## Sobre mim

Atualmente, estou cursando Ciência da Computação na **UNIFAL** (Universidade Federal de Alfenas), onde venho construindo uma base sólida em desenvolvimento de software e resolução de problemas.

Também atuo como **desenvolvedor Full Stack** no [Sistema IO](https://sistemaio.com.br/), onde desenvolvo scripts em PHP/Laravel para processamento de dados, analiso requisições e respostas HTTP pelo DevTools e desenvolvo códigos de web scraping.

No momento, estou me dedicando a aprimorar minhas habilidades em desenvolvimento web, explorando tecnologias de frontend e backend, além de aprofundar meus conhecimentos em bancos de dados e integrações com APIs. Estou sempre aberto a novos desafios e oportunidades de aprendizado, especialmente em projetos que combinem criatividade e tecnologia.

💬 **Idiomas:** Português (nativo) · Inglês (intermediário)
